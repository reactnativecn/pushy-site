# Analytics screenshots

Real browser captures from the local `pushy-admin` analytics UI, captured on
2026-09-12. All application names, versions, request counts and device data are
fictional. These images are not customer evidence.

The source checkout provides `bun run dev:analytics` and
`scripts/ANALYTICS-DEMO.md` to reproduce the datasets and capture steps.
Pushy captures use the existing analytics worktree
`pushy-admin/.claude/worktrees/nostalgic-bose-567f32` (base e21df45).
Cresc captures use `cresc-admin` (base 6cb123c).

Files: `overview.webp`, `versions.webp`, `traffic.webp`,
`traffic-hours.webp`, `failures.webp`, `failure-dimensions.webp`.
Images were losslessly encoded from browser PNGs; the UI contents were not
reconstructed or composited. The homepage only loads the selected primary
image. Documentation includes the two supplementary detail captures.
